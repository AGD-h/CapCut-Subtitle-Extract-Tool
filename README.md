# CapCut 剪映批量纯字幕提取工具
> 一键批量提取剪映/CapCut全草稿纯中文字幕，自动过滤数字、乱码、特殊符号，Windows免环境双击即用。

---

## 核心功能
- 全草稿批量处理：一次性扫描提取所有剪映工程字幕，无需逐个手动导出
- 纯净字幕过滤：仅保留纯中文+标准中文标点，自动剔除数字编号、乱码、无效符号
- 自动整理输出：每个草稿生成独立字幕文件，按时间+工程名命名，自动保存到桌面专属文件夹
- 零门槛即用：打包好的exe无需安装Python环境，Windows电脑双击直接运行
- 异常容错：损坏/无字幕草稿自动跳过，不中断整体任务

---

## 使用方法
1.  定位剪映工程根目录，Windows默认路径：
    ```
    C:\Users\你的用户名\AppData\Local\CapCut\User Data\Projects\com.lveditor.draft\
    ```
    *快速打开：Win+R输入 `%LocalAppData%\CapCut\User Data\Projects\com.lveditor.draft` 回车直达*
2.  从本仓库右侧「Releases」下载最新版 `剪映批量字幕提取工具.exe`
3.  将exe文件放入上述剪映工程根目录
4.  双击exe运行，等待处理完成，字幕文件自动保存到桌面「剪映批量提取字幕」文件夹

## 常见问题
### Q1：运行提示找不到 `draft_content.json`
A：请确保exe已放入剪映工程根目录 `com.lveditor.draft` 文件夹内，而非其他路径。

### Q2：杀毒软件提示风险/无法运行
A：属于Python打包exe的正常误报，本工具源码完全开源，无任何恶意代码。可将exe加入信任区放行，也可自行下载源码本地打包。

### Q3：无字幕提取结果
A：请确认剪映工程内有有效字幕内容，空工程/无字幕工程会自动跳过；同时确认exe存放路径正确。

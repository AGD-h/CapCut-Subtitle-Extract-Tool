\# 剪映/CapCut 批量纯中文字幕提取工具

一键批量提取剪映/CapCut所有草稿里的纯中文字幕，自动过滤数字、乱码、特殊符号、无效内容，无需手动配置，双击即用。



\## 功能特点

\- 🚀 全自动批量处理：一次性提取所有剪映草稿的字幕，无需逐个操作

\- 🧹 纯净字幕过滤：只保留纯中文汉字+标准中文标点，彻底删除数字编号、英文、乱码、特殊符号

\- 📂 自动保存：每个草稿生成独立的字幕文件，自动保存到桌面专属文件夹，好找不乱

\- 📦 零依赖：打包好的exe无需安装Python环境，Windows电脑双击直接运行

\- 🛡️ 异常容错：损坏/无字幕的草稿自动跳过，不会中断整体任务
